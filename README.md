# AnyGarbs

Landing page for anygarbs.com: AI-driven robot swarms that turn any garbage into graded raw materials.

Static site, no build step. Open `index.html` or serve the folder.

- `index.html` — markup
- `css/style.css` — styles
- `js/sprites.js` — pixel-art palette, sprite grids and renderer
- `js/page.js` — inline sprites and stat pips
- `js/scene.js` — the animated hero scene
